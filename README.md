# pubg-record-cli
배틀로얄 게임의 판별 무기 딜량을 기록하는 콘솔 프로그램

## 기능 (1단계)
- 무기 등록 / 목록 조회 / 삭제
- 판 기록 입력 (등록된 무기를 고르고 딜량 입력)
- 전체 기록 조회 / 기록 삭제

## 검증 규칙
- 딜량은 0 이상
- 무기 이름은 빈 문자열과 중복 불가
- 한 판에 같은 무기는 한 번만, 무기 기록은 최소 1개
- 기록에 쓰인 무기는 삭제 불가

## 추후 추가
- 수정 기능, 무기별 통계 (JDBC 교체 후)

## 기술
Java 21, Gradle (이후 MySQL/JDBC)
